외화예금 전표 자동변환기

외화계좌 엑셀과 환율 파일을 올리면 자동으로 원화 환산해서 전표 형식으로 만들어줍니다. 모든 처리는 이 화면 안에서만 이뤄지고 파일은 어디에도 전송되지 않아요.

1 파일 올리기

외화계좌 엑셀과 환율 파일, 두 가지만 올리면 됩니다.
여기로 끌어다 놓거나 클릭해서 선택
(여러 계좌·여러 파일 동시 선택 가능)
여기로 끌어다 놓거나 클릭해서 선택

2 확인 후 다운로드

빨간색 행은 확인이 필요한 거래예요. 셀을 클릭하면 바로 고칠 수 있어요. 계정·거래처를 채우면 자동으로 규칙에 저장돼서 다음에도 같은 적요는 자동 분류돼요.
통장적요
(참고용, 다운로드에 안 들어감)		 적요 접두어 거래일자 구분 계정 정보 거래처 차변 대변 적요 참고(적용환율)
년월일 코드계정과목 코드거래처명

거래처 등록 및 관리 (선택사항)

거래처를 등록해두면 변환하기 탭에서 골라 쓸 수 있어요. 거래처마다 전용 규칙(계정과목·거래처코드·보통예금 계정)을 따로 저장해요.
아직 등록된 거래처가 없어요. "+ 새 거래처"를 눌러 추가해보세요.
거래구분에 "결산"이 포함된 거래는 자동으로 계정과목 이자수익(901) + 위 거래처로 처리돼요.
통장적요에 이 단어가 있으면코드계정과목거래처코드거래처명

상대계정 규칙 (공통) (선택사항)

적요에 특정 단어가 있으면 상대 계정을 자동으로 채워주는 공통 규칙이에요.
통장적요에 이 단어가 있으면코드계정과목거래처코드거래처명

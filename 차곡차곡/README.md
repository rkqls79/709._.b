# 차곡차곡

방송통신대 학업, 자격증 준비, 세무 실무, 개인 생활을 한곳에서 관리하는 개인용 웹 앱입니다.
**설치도 서버도 필요 없이 `index.html` 파일 하나로 동작합니다.**

## 열기

```
index.html 을 크롬으로 열면 끝입니다.
```

다만 아래 두 기능은 브라우저 보안 정책상 **로컬 서버나 https 주소**에서만 동작합니다.

| 기능 | `file://` 로 직접 열 때 | 로컬 서버 · https |
|---|---|---|
| 자료실 첨부 파일 | ✗ (링크·메모는 가능) | ✓ |
| 크롬 알림 | ✗ | ✓ |

로컬 서버로 여는 방법 — 이 폴더에서:

```bash
python -m http.server 8123
```

그다음 `http://localhost:8123` 로 접속합니다.

## 화면

주소의 `?app=` 값으로 화면이 정해집니다.

| 주소 | 화면 |
|---|---|
| `index.html` | 홈 — 오늘 할 일 한눈에 |
| `?app=sched` | 통합 일정 — 월/주/일 달력, 드래그로 날짜 변경 |
| `?app=manage` | 관리 — 전체 메뉴 허브 |
| `?app=progress` | 통계 — 학습·생활·업무 진행 분석 |
| `?app=univ&p=...` | 대학 — 강의, 과제·시험, 성적·졸업, 자료실 |
| `?app=life&p=...` | 개인·업무 — 자격증, 습관, 운동·건강, 세금·신고, 메모 |

## 데이터

모든 기록은 **이 브라우저의 localStorage**에만 저장됩니다. 서버로 전송되지 않습니다.

- `lm.univ.v1` — 학기, 과목, 과제·시험, 자료실
- `lm.life.v1` — 자격증, 배움, 습관, 운동, 세무 업무, 메모, 개인 일정
- `lm.theme` · `lm.ui.scale` · `lm.notify.v1` — 화면 설정
- 첨부 파일은 IndexedDB(`lm.files`)에 따로 저장됩니다

브라우저를 바꾸거나 기기를 옮길 때는 **설정 → 데이터 → 백업 파일 내보내기 / 불러오기** 를 쓰세요.
(내보낸 JSON에는 실제 기록이 들어 있으므로 저장소에 올리지 않도록 `.gitignore`에 넣어 두었습니다.)

## 파일 구조

```
index.html      앱 전체 (디자인 · 공통 기능 · 화면 6개)
```

`index.html` 한 파일 안이 이렇게 나뉘어 있습니다.

1. `<style>` — 디자인 (테마 5종, 공통 부품, 반응형, 모바일 최적화)
2. `<template id="tpl-*">` — 화면별 마크업 (한 번에 한 화면만 꺼내 붙입니다)
3. 첫 번째 `<script>` — 저장소, 공휴일 계산, 사이드바, 일정 수집, 알림, 엑셀 읽기
4. 두 번째 `<script>` — 세무 신고기한 생성기
5. 세 번째 `<script>` — 화면별 코드 `bootHub` · `bootSched` · `bootUniv` · `bootLife` 등

## 만든 기능

- **통합 일정** — 대학·자격증·업무·개인 일정을 한 달력에, 드래그로 날짜 변경, 반복 일정, 알림
- **과제·시험** — 체크리스트 기반 준비 진행률, 제출 관리, 시험 범위·방식
- **성적·졸업** — 학기별 카드에서 성적 바로 입력, 계절학기 추가, 졸업 요건 자동 계산
- **자료실** — 강의·주차별 분류, PDF·이미지·영상 미리보기, 태그·즐겨찾기
- **자격증** — 관심 → 준비 → 접수 → 응시 → 결과 → 취득 단계 관리
- **배우고 싶은 것 / 실무 공부** — 단계형 로드맵, 마일스톤, 학습 기록
- **습관 · 운동** — 연속 기록, 주간 목표(횟수·시간), 체중 목표 도달 예상
- **세금·신고** — 법정 신고기한 자동 생성(주말·공휴일 보정), 반복 업무 규칙
- **공휴일** — 연도 제한 없이 자동 계산 (설날·추석은 음력을 천문 계산으로 환산)

## 브라우저

크롬 기준으로 만들었습니다. 엣지·사파리·파이어폭스도 동작하지만 일부 기능(알림, 화면 배율)은 크롬에서 가장 안정적입니다.
